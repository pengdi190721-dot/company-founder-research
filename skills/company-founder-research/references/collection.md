# 收集与核对方法

## 一、检索矩阵

按实际对象替换下列词，先使用精确名称，再补简称、品牌、曾用名、老板名与产品名。不是每行都必须执行；选择能补足当前字段的查询。

| 模块 | 查询方向 | 优先材料 |
|---|---|---|
| 企业身份 | 公司全称＋城市／地址；公司名＋品牌／曾用名／关联公司 | 公开登记、企业官网、政府与协会企业介绍 |
| 老板身份 | 公司名＋老板名；老板名＋创始人／董事长／法定代表人／实际控制人 | 企业领导介绍、登记及正式披露、本人采访、原发媒体 |
| 产品与业务 | 公司名／品牌＋产品／目录／应用／客户案例 | 官网产品页、目录、公司正式发布、客户原始公开资料 |
| 创业与沿革 | 老板名＋创业／创办／采访；公司名＋发展历程；品牌＋创立 | 本人访谈、官网沿革、登记、早期原发报道 |
| 官网与账号 | 公司名／品牌／老板名＋官网／视频号／抖音 | 官网账号入口、平台主页及认证资料、企业公开公告 |
| 介绍与采访 | 公司名／老板名＋专访／人物／访谈／演讲／创业故事／论坛 | 原发媒体、政府人物报道、协会活动、公开视频文字稿 |

对采访同时搜索历史名称与当时职务，不只搜索当前公司全称。可追加行业、城市、展会名、产品名等排除同名人物。

## 二、工具选择与降级

1. 先检查当前会话提供的工具；有资料搜索技能时按其可用渠道执行。
2. 通用网页搜索发现入口，读取正文核对。来源为网页、公开文件、账号主页、视频文字稿或用户材料时分别记录。
3. 页面依赖动态加载时使用当前可用浏览器；不是每次任务都必须安装工具或新建账号。
4. 抖音可用平台搜索、公开主页、公开分享链接和已有授权会话。短链接解析后保留原链接与最终链接，确保指向正确对象。
5. 视频号可用已配置的平台服务、现有授权会话、官网入口和用户提供的分享材料。第三方搜索结果只是线索，仍需核对作者与企业关系。没有可用服务时不虚构调用，也不把网页搜索冒充站内搜索。
6. 某平台被登录或验证码阻挡，注明“无法访问”；尚未执行平台搜索则注明“未检索”。在其他渠道补查并继续能完成的工作。

不自动购买第三方服务。是否采用某个服务取决于当次配置、授权及可观测结果，不设固定服务商。

## 三、来源底稿

对每条有用来源记录：

| 字段 | 记录内容 |
|---|---|
| 来源编号 | 来源01、来源02……；更新时尽量稳定 |
| 标题、发布方 | 实际页面标题与发布机构／账号 |
| 链接／文件 | 原始入口；用户材料记录文件名与页码或图片位置 |
| 日期 | 发布时间／更新时间、检索日期分别填写；未知写未标日期 |
| 实际读取材料 | 正文、公开登记、文件、账号主页、完整视频／文字稿、部分文字稿、摘要、截图 |
| 访问状态 | 完整读取、部分读取、无法访问、仅搜索摘要 |
| 支持的字段 | 对应主体、时间口径、具体事实及短证据定位 |
| 来源性质 | 登记／正式披露、企业自述、本人自述、媒体、转载、用户提供 |
| 冲突与局限 | 未独立核对、历史职务、账号归属不明等 |

转载要追溯原发文章。原文无法访问时保留转载出处，明确“原文未核对”，不将转载数量当独立核实次数。

## 四、年份和人物的特殊处理

- “1998年开始做生意，2005年注册公司”：个人创业年份为1998年（注明自述及来源），公司成立年份为2005年（登记支持）；品牌年份另查。
- “二十多年前创业”：保留原句及采访日期，不强行转换为精确年份；可给范围时标为推算并解释方法。
- “公司成立于2001年”与当前主体登记为2012年：先查前身、改名、品牌或主体更换。无法解释就并列冲突，不武断判定其中一项错误。
- 历史报道称某人为董事长，近期官网列出另一位：将旧身份纳入沿革；现任职务按最新可验证资料登记并注明日期。
- 商业地址可能是办公地、工厂、门店或注册地；照片、地图和用户地址只用于辅助定位，不能代替注册信息。

## 五、账号归属

账号分类为企业官方、老板个人、品牌、员工、经销商、第三方。官方归属需要至少一条直接且可回查的依据，例如认证主体匹配、官网明确链接、企业或本人公开确认；只有昵称或照片时为待确认。

记录账号名、平台、可见账号标识、主页／分享入口、认证信息、归属依据、检索日期。某个平台没有稳定主页链接时，提供账号名＋账号标识＋可用分享入口或主页截图定位；不编造链接。

## 六、采访与故事

逐篇记录标题、媒体／主办方、发布日期、链接、采访对象、当时职务、实际读取材料与关键内容。全文相同的转载合并为一条，并保留原发入口与必要的可访问备份。

视频已有文字稿就核对文字稿覆盖范围；需要转写且当前有可用工具时再转写，不能把标题、评论、封面文字当采访内容。故事条目写“公开发生的事件／行为＋原话依据＋尚需访谈确认的细节”，不直接写成戏剧化脚本。

公司介绍：原文入口＋合规短摘录＋自写摘要。摘录遵守当次环境的版权限制，完整文章不能仅因公开可访问而全文复制。

## 七、停止与补充

重要缺口优先补搜原始来源、曾用名、城市和关联事件。若同名问题尚未解决、来源持续无法访问或补搜不再产生有效证据，记录已经尝试的路径与具体补充材料。保留能确定的结果，不反复重试同一阻塞渠道。

优先请求能一次解决缺口的材料，如企业全称／营业执照名称、官网、老板主页、视频号分享入口、采访文字稿。只在必须识别对象时先问；其余缺口放入最终待补清单。
